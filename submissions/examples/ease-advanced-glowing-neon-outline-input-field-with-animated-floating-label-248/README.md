# Glowing Neon Outline Input Field with Animated Floating Label

## Overview

A compact mobile-first neon input component featuring glowing
outline effects and smooth animated floating labels.

Built with pure HTML, CSS, and JavaScript.

## Features

- ⚡ Neon glowing input borders
- ✨ Animated floating labels
- 🎨 Cyberpunk glassmorphism style
- 📱 Mobile-first responsive design
- 🌈 Gradient glow effects
- 🖱️ Smooth focus animations
- 🚀 Pure HTML/CSS/JS

## Usage

1. Open `demo.html` in your browser.
2. Click inside the input fields.
3. Experience animated labels and neon effects.
