# Hover Modal with SaaS Modern Styling

A responsive SaaS-inspired hover modal component built using pure
HTML and CSS.

The component provides contextual information when a user hovers
over a product card, creating a modern interaction without requiring
JavaScript.

## Features

- Pure HTML and CSS
- No JavaScript dependency
- SaaS-inspired visual design
- Hover-triggered contextual modal
- Smooth reveal animation
- Product status indicators
- Statistics section inside modal
- Multiple demo cards
- Responsive desktop, tablet, and mobile layouts
- Keyboard focus support
- Reduced-motion support
- Modern borders and subtle shadows

## Files

- `demo.html` — component markup and demo content
- `style.css` — complete styling, animation, and responsive behavior
