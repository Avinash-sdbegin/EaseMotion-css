# Animated Toggle with Dark Mode Styling

A responsive animated toggle component created using pure HTML and CSS.

## Features

- Dark mode inspired visual design
- Smooth toggle animation
- Animated thumb movement
- Sun and moon indicators
- Responsive mobile layout
- Keyboard focus support
- Accessible label
- Reduced-motion support
- Soft neumorphic surface styling
- Pure HTML and CSS
- No JavaScript dependency

## Files

- `demo.html` — component markup
- `style.css` — complete styling and responsive behavior

## Responsive Design

The toggle card adapts to smaller screens by stacking the content vertically,
making the component comfortable to use on mobile devices.

## Accessibility

The toggle uses a native checkbox input with an accessible label and visible
keyboard focus state.

Users who prefer reduced motion are supported through
`prefers-reduced-motion`.

## Usage

Open `demo.html` in a browser to preview the component.
