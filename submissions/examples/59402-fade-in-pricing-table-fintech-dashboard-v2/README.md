# CSS Fade-In Pricing Table for Fintech Dashboard Layouts

A modern **Fade-In Pricing Table** built using pure HTML and CSS for fintech dashboards, SaaS products, digital banking platforms, and financial applications.

## Features

* Pure HTML5 & CSS3
* Staggered fade-in card animations
* Responsive pricing table
* Modern glassmorphism design
* CSS custom properties
* Smooth hover interactions
* No JavaScript required
* Supports `prefers-reduced-motion`

## Folder Structure

## Usage

1. Open `demo.html` in any modern browser.
2. Customize plan names, pricing, and features.
3. Modify colors using the CSS variables in `:root`.
4. Integrate the pricing table into your fintech dashboard or landing page.
