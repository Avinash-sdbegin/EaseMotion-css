# CSS Shimmer-Sweep Modal for Product Catalog Layouts

A modern **Shimmer-Sweep Modal** built using pure HTML and CSS for EaseMotion CSS.

## Features

- Pure HTML5 & CSS3
- Elegant shimmer sweep animation
- Smooth modal entrance
- Product catalog ready layout
- Responsive design
- CSS Custom Properties
- Accessible structure
- Supports `prefers-reduced-motion`
