# 3D Perspective Tilt Product Showcase Card with Light Reflections

### Compact Mobile-First Edition

A modern **3D Perspective Tilt Product Showcase Card** built with **HTML5** and **CSS3**. The component features a realistic 3D tilt effect, animated light reflections, glassmorphism styling, and a responsive mobile-first layout for premium product showcases.

---

## ✨ Features

- 3D perspective tilt animation
- Animated light reflection (shine effect)
- Glassmorphism product card
- Mobile-first responsive layout
- Smooth hover transitions
- Gradient CTA button
- CSS Variables for easy customization
- Keyboard accessibility
- `prefers-reduced-motion` support
- Pure HTML & CSS implementation

## 🚀 Usage

1. Open the component folder.
2. Keep `demo.html` and `style.css` together.
3. Open `demo.html` in any modern browser.
4. Hover over the card to experience the 3D perspective tilt and animated light reflection.

No external libraries or build tools are required.
