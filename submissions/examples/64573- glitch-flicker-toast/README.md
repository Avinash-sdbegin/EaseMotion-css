# ⚡ CSS Glitch-Flicker Toast for Minimalist Tech Layouts

A lightweight **pure HTML + CSS animated toast notification** created for the EaseMotion CSS collection.

This component uses glitch-style motion, neon effects, and flicker animations to create a futuristic minimalist tech interface element.

---

## ✨ Features

- Pure HTML & CSS implementation
- No JavaScript required
- Glitch entrance animation
- Neon light sweep effect
- Flicker motion effect
- Responsive design
- Modern cyber-tech UI style
- Accessible reduced-motion support
