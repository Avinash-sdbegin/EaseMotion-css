# 3D Rotating Cube Navigation Menu for Interactive Landing Pages

## Overview

A glassmorphic 3D cube navigation component featuring smooth rotation,
interactive controls, and futuristic landing page navigation.

Built using pure HTML, CSS, and JavaScript.

## Features

- 🧊 3D rotating cube navigation
- ✨ Glassmorphism UI style
- 🔄 Smooth cube transitions
- 🎨 Gradient neon effects
- 🖱️ Interactive navigation controls
- 📱 Responsive mobile layout
- ⚡ Pure CSS 3D transforms

## Usage

1. Open `demo.html` in browser.
2. Click navigation buttons.
3. Cube rotates to reveal different sections.
