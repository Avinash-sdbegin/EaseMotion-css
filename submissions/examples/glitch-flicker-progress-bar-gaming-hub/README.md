# Glitch Flicker Progress Bar for Gaming Hub Layouts

A futuristic **Glitch Flicker Progress Bar** built with pure HTML and CSS for gaming dashboards, esports platforms, cyberpunk interfaces, loading screens, and modern gaming hub layouts.

## Features

* Pure HTML5 & CSS3
* Smooth glitch flicker animation
* Neon glow effects
* Multiple color variants
* Responsive design
* No JavaScript required
* Accessible with `prefers-reduced-motion` support
* Easy customization using CSS custom properties


## CSS Custom Properties

```css
:root{
  --bg:#070b12;
  --card:#111827;
  --track:#1f2937;
  --text:#ffffff;
  --muted:#94a3b8;
  --radius:14px;
  --speed:2.2s;
}
```

## Usage

1. Open `demo.html` in any modern browser.
2. Customize the progress percentage using:

```html
<div class="glitch-progress cyan" style="--progress:92%;">
```

3. Change colors or animation speed through the CSS variables.
