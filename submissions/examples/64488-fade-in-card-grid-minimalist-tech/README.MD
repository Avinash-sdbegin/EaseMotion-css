# Fade-In Card Grid for Minimalist Tech Layouts


## Overview

A modern minimalist card grid built using pure HTML and CSS.

The component uses smooth fade-in and slide-up entrance animations
to create an elegant technology focused UI.


## Features

- Pure HTML and CSS
- Smooth fade-in animation
- Responsive card grid layout
- Hover elevation effect
- Lightweight performance
- Mobile friendly design
- Accessible reduced motion support
