# CSS Northern Lights Curtain

A CSS-only animated Northern Lights curtain component for EaseMotion CSS.

## Overview

`CSS Northern Lights Curtain` creates a flowing Aurora Borealis effect using pure CSS animations.

## Features

- Pure CSS implementation
- No JavaScript dependency
- Responsive design
- Smooth aurora wave movement
- Multiple layered light curtains
- Accessibility support with reduced motion preference
