# CSS Morph-Glow Feature Grid for Responsive Dashboard Layouts

A modern **Morph-Glow Feature Grid** component built using only **HTML5 and CSS3**. This showcase demonstrates animated glow effects, morphing shapes, responsive dashboard cards, and accessibility support without JavaScript.

---

## ✨ Features

- 🌈 Morphing glow animations
- 💡 Animated feature cards
- 🎨 Dynamic gradient effects
- 💎 Glassmorphism dashboard UI
- ⚡ Smooth CSS transitions
- 🎯 CSS Custom Properties
- 📱 Fully responsive grid layout
- 🧩 Pure HTML5 & CSS3
- ♿ `prefers-reduced-motion` support
- 🚫 No JavaScript required

---

## 🚀 Usage

1. Open `demo.html` in a modern browser.
2. Hover over feature cards to activate glow and morph effects.
3. Customize colors and animation properties using CSS variables.
