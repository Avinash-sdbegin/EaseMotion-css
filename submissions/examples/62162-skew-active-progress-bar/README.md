# Skew Active Progress Bar

A modern pure CSS animated progress bar created for EaseMotion CSS.

This component demonstrates a skew-transform based active progress indicator suitable for SaaS dashboard and product showcase layouts.

## Features

- Pure HTML and CSS
- Skew active animation effect
- Modern SaaS inspired glass UI
- Smooth keyframe animation
- Responsive design
- Lightweight implementation
- No JavaScript dependency
- Prefers-reduced-motion support
