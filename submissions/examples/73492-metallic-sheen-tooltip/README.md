# CSS Tooltip: Metallic Sheen

A pure CSS tooltip and popover component featuring a refined
metallic-sheen visual treatment.

## ✨ Features

- Metallic gradient surfaces
- Smooth tooltip transitions
- Hover interaction
- Keyboard focus interaction
- Top-positioned tooltip variation
- CSS-only popover using `<details>` and `<summary>`
- Responsive layout
- Dark-mode compatible styling
- Hardware-friendly CSS transforms
- Visible keyboard focus states
- `prefers-reduced-motion` support
- No external dependencies

## 🎨 Variations

### 1. Default Tooltip

A metallic tooltip appears above the trigger when the user hovers
or focuses the button.

### 2. Top/Directional Tooltip

Demonstrates a tooltip with a different placement direction.

### 3. Interactive Popover

Uses native `<details>` and `<summary>` elements to create an
interactive CSS-only information panel.

## ♿ Accessibility

The demo includes:

- Semantic buttons
- `aria-describedby` for tooltip relationships
- `role="tooltip"`
- Keyboard-focusable triggers
- Visible `:focus-visible` styles
- Semantic `<details>` and `<summary>`
- Reduced-motion support

## ⚡ Performance

The interaction effects use CSS transitions and transforms.
No JavaScript animation loop is required.

## 🛠️ Technologies

- HTML5
- Vanilla CSS

No external libraries or frameworks are required.
