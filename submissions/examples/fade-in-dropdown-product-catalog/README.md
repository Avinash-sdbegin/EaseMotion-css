# CSS Fade-In Dropdown Product Catalog

A lightweight and modern dropdown component created using pure HTML and CSS.

This project demonstrates a smooth fade-in dropdown interaction for product catalog layouts with responsive design and accessibility support.

## ✨ Features

- Pure HTML and CSS implementation
- Smooth fade-in dropdown animation
- Hover based interaction
- Modern product card layout
- Responsive across devices
- No JavaScript required
- Reduced motion accessibility support

## 📁 Structure

## 🚀 Usage

1. Clone the repository.

2. Navigate to this folder.

3. Open `demo.html` in your browser.
