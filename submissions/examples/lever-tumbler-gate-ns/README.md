# Lever Tumbler Gate

A pure HTML and Vanilla CSS motion example for EaseMotion CSS issue #77696.

## Concept

Lever Tumbler Gate is a mechanical-inspired CSS animation where multiple
lever tumblers move and gradually align around a central bolt.

The entire motion is created with CSS keyframes.

## Features

- Pure CSS animation
- Multiple staggered lever movements
- Central bolt mechanism
- Mechanical metallic styling
- Responsive layout
- Dark-mode friendly visual design
- CSS transform-based animation
- `prefers-reduced-motion` support
- No external dependencies
