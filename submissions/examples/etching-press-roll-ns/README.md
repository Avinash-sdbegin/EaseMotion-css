# Ease Etching Press Roll

A CSS-only animated intaglio etching press roller component for EaseMotion CSS.

## Overview

`ease-etching-press-roll` recreates an etching press mechanism where a heavy roller moves across a printing plate using CSS animations.

## Features

- Pure CSS animation
- No JavaScript dependency
- Industrial printing themed UI
- Animated press roller movement
- Plate interaction effect
- Handle movement animation
- Responsive design
- Reduced motion support
