# CSS Morph-Glow Feature Grid for SaaS Showcase Layouts

A modern **Morph-Glow Feature Grid** component built using pure HTML5 and CSS3 for SaaS showcase layouts. This component provides animated feature cards with morphing glow effects, smooth hover interactions, glassmorphism styling, and responsive behavior.

## Features

* Pure HTML5 & CSS3
* No JavaScript required
* Animated morphing glow effects
* Modern SaaS feature showcase layout
* Responsive feature grid system
* Glassmorphism card design
* Gradient glow backgrounds
* Smooth hover lift and scale animation
* Animated feature icons
* CSS-only keyframe animations
* CSS Custom Properties for easy customization
* Optimized responsive behavior
* Supports `prefers-reduced-motion`

## Usage

1. Open `demo.html` in any modern browser.
2. Hover over feature cards to view morphing glow animations.
3. Customize colors, shadows, spacing, and animation behavior using CSS variables inside `:root`.

## CSS Custom Properties

```css
:root{
  --bg:#eef4ff;
  --surface:rgba(255,255,255,.9);
  --primary:#2563eb;
  --secondary:#06b6d4;
  --accent:#8b5cf6;
  --text:#111827;
  --muted:#64748b;
  --shadow:0 25px 60px rgba(37,99,235,.18);
  --radius:28px;
}
```
