# Shift Basket Raise

A pure HTML and Vanilla CSS motion example for EaseMotion CSS issue #77686.

## Concept

Shift Basket Raise uses a mechanical instrument-inspired visual to
demonstrate a basket moving vertically through a guided mechanism.

The animation is created entirely with CSS keyframes.

## Features

- CSS-only animation
- Staggered motion elements
- Smooth vertical basket movement
- Mechanical housing and guide rails
- Responsive layout
- Dark interface styling
- Hardware-friendly transforms
- `prefers-reduced-motion` support
- No external dependencies
