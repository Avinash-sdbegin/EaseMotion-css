# Glitch-Flicker Feature Grid for Glassmorphism UI

A futuristic glassmorphism feature grid created using pure HTML and CSS.

This component provides a modern UI showcase with glitch text effects,
floating cards, neon hover interactions, and smooth animations.


## Features

- Pure HTML and CSS
- No JavaScript dependency
- Glassmorphism design
- Glitch flicker text animation
- Floating feature cards
- Neon hover glow effect
- Responsive layout
- Accessibility support with prefers-reduced-motion
