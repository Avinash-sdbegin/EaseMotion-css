# CSS Fade-In Pricing Table for Fintech Dashboard Layouts

A modern **Fade-In Pricing Table** component built using pure HTML5 and CSS3 for fintech dashboard layouts.

This component provides a clean pricing experience with smooth entrance animations, highlighted plans, glassmorphism cards, and responsive design.

---

## ✨ Features

- Pure HTML5 and CSS3 implementation
- No JavaScript dependency
- Fintech dashboard pricing layout
- Smooth fade-in entrance animations
- Featured pricing plan highlight
- Glassmorphism card design
- Hover elevation effects
- Gradient action buttons
- Animated pricing cards
- Fully responsive layout
- CSS custom properties support
- Lightweight CSS animations
- `prefers-reduced-motion` accessibility support
