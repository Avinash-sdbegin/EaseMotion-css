# CSS Fade-In Badge for SaaS Showcase Layouts

A modern SaaS showcase badge component featuring smooth fade-in animations, glowing indicators, gradient styling, and responsive showcase cards.

This component is built completely with HTML and CSS without any JavaScript or external dependencies.

## ✨ Features

- 🌟 Smooth fade-in badge animation
- 🟢 Animated status indicator
- 🎨 Modern SaaS landing page styling
- 💎 Glassmorphism card design
- ⚡ Pure HTML and CSS implementation
- 📱 Fully responsive layout
- ✨ Smooth hover interactions
- ♿ Accessibility support with `prefers-reduced-motion`

## 🚀 Usage

1. Clone the EaseMotion CSS repository.

2. Navigate to the component folder:


submissions/examples/ease-css-fade-in-badge-saas-showcase-layouts/


3. Open `demo.html` in any modern browser.

No installation, framework, or external library is required.

## 🎨 CSS Custom Properties

The component uses CSS variables for easy customization:

```css
:root {
    --bg: #070b18;
    --primary: #00f5ff;
    --secondary: #8b5cf6;
    --green: #22c55e;
    --text: #f8fafc;
    --muted: #94a3b8;
}

Update these values to customize colors and branding.
