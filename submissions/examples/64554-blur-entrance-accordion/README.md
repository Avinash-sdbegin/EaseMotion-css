# Blur Entrance Accordion

A modern pure CSS animated accordion component created for **EaseMotion CSS**.

This example demonstrates a smooth blur entrance animation with a minimalist tech-inspired glass UI design.

## ✨ Features

- Pure HTML & CSS implementation
- Smooth blur entrance animation
- Glassmorphism design
- Native HTML `<details>` accordion
- No JavaScript dependency
- Responsive across devices
- Lightweight and performant
- Accessible motion support
- `prefers-reduced-motion` support
